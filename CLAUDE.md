# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview
Static website for "The Tin Music and Arts" venue using HTML with TailwindCSS.

## Build/Test Commands
- No build tools or package managers are used in this project
- This is a static HTML site, simply open the HTML files in a browser to test

## Code Style Guidelines
- HTML: Use 2-space indentation
- CSS: Follow existing pattern of placing styles in head or dedicated style tags
- Images: Use relative paths (e.g., `/image.jpg`) 
- Maintain responsive design using TailwindCSS classes
- Follow existing naming conventions (kebab-case for class names)
- Keep markup semantic and accessible
- Maintain mobile-friendly UI with responsive Tailwind classes
- Preserve sticky scrolling effect pattern for event displays
- Use existing color scheme (#d85b61, #edc656, #0b8793)
